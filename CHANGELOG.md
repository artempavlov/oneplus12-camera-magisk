# Changelog

## 6.0

- Fixes the unintended crop in stock OnePlus Camera Photo when the expanded RAW profile is active.
- Uses a separate, camera-only Photo Compatibility APK in Vector. The late boot stage checks its checksum, the stock camera version, and the Vector scope before applying the expanded sensor profile.
- Keeps the four firmware patches, existing Magisk module ID, and stock-file checksum checks from 5.0.

## 5.0

- Adds sensor digital gain for 50 MP RAW at up to ISO 6400.
- Keeps the auxiliary lenses, both RAW resolutions, 8K video, and 2048 x 1152 slow motion from version 4.
- Keeps the existing Magisk module ID and firmware checks.

## 4.0

- Combines the Camera Aux and Dual RAW modules in one ZIP.
